# AuraCleaner

> **极简 · 纯净 · 高性能的原生 macOS 垃圾清理与专业软件卸载工具**

---

## 📖 产品简介

`AuraCleaner` 是一款专为 Mac 用户打造的原生系统清理与深度卸载工具。它专注于以极简透明的方式帮您找回磁盘空间，彻底清除顽固残留，保持系统的轻快与纯净。

---

## 🌟 核心功能

### 🧹 深度系统清理
- **系统与应用缓存**：智能识别系统及应用程序运行产生的无用缓存、日志与临时文件，一键安全释放磁盘空间。
- **孤立残留清理**：自动扫描已被移除的应用遗留在系统深处的配置、数据与支持文件，不留无用死尸项。
- **陈旧与大文件清理**：按体积与时间全景透视磁盘占用，快速定位并清理长期闲置的大文件。
- **安全防护机制**：严格遵循安全边界，只清理可安全重建的数据，绝不触碰个人核心文档与系统保留文件。

### 📦 软件彻底卸载
- **一键深度卸载**：超越简单的“移到废纸篓”，连同应用本体、容器目录、应用支持文件、偏好设置一并完整清除。
- **智能残留确权**：精准定位应用专属关联项，杜绝多应用共用资源的误杀，同时不漏掉任何隐蔽尾巴。
- **清理伴生服务**：自动检测并清理随软件安装的后台守护项与开机自启动配置，彻底告别后台暗中消耗资源。

### 🎨 原生极简美学
- **现代 macOS 原生体验**：采用纯粹微晶质感界面设计，视觉内敛干净，无任何浮夸广告或弹窗打扰。
- **轻量秒启与零常驻**：无需沉重的后台驻留进程，打开即用，用完即走，不浪费一丝系统内存。
- **清晰透明可控**：所有扫描出的项目均提供完整清晰的路径与大小展示，删除决策权完全交由用户掌控。

## 📥 下载与安装

前往 **[Releases 发布页面](https://github.com/8wcznkmy6b-del/AuraCleaner/releases)** 下载最新版 DMG 安装包（如 `AuraCleaner-1.0.2.dmg`）。

双击打开下载的 DMG 镜像，直接将 `AuraCleaner.app` 拖入 `Applications`（应用程序）文件夹即可完成安装。

### 系统要求
- macOS 14.0 (Sonoma) 或更高版本
- 原生支持 Apple Silicon (M1/M2/M3/M4 系列芯片) 及 Intel Mac 架构
- 首次使用时需授予「完全磁盘访问权限」以完成全盘扫描与深度残留清理
