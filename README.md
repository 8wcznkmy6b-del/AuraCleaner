# AuraCleaner

> **简洁、安心的 macOS 垃圾清理与软件卸载工具**

---

## 📖 产品简介

`AuraCleaner` 是 AuraSnap 的配套应用，帮您清理 Mac 上不再需要的缓存、日志和残留文件，也能把软件连同它的相关数据一起卸载干净，腾出磁盘空间。

所有扫描结果都会先列出来给您确认。普通文件删除时移入废纸篓，清空废纸篓之前都能放回原处；需要管理员授权的系统级项目（如 `/Library` 下的后台服务）无法放进废纸篓，处理前请仔细确认。

---

## 🌟 核心功能

### 📊 空间构成
- 拆解整块磁盘：macOS 系统卷、启动与恢复卷、虚拟内存按 APFS 各卷实际占用列出；数据卷按目录实测，分为应用程序、用户文件、应用数据与缓存、开发环境、共享与临时数据、系统资源与日志。
- 每一类写明是什么、能否清理、怎么减少，清不掉的部分（系统卷、虚拟内存、快照、无权限读取的系统数据）说明原因；可逐层查看最大的文件夹。只读，不删除任何东西。

### 🧹 系统清理
- **缓存与日志**：找出系统和应用运行中产生的缓存、日志与临时文件。缓存删除后通常会由应用按需重新生成，但部分应用可能需要重新下载资源或重新登录。
- **孤立残留**：找出已删除的应用遗留下来的配置与数据文件，包括写在「影片 / 音乐 / 图片 / 文稿」文件夹里的工作数据（如剪映的 `~/Movies/JianyingPro`）。这类目录可能含草稿或作品，默认不勾选。
- **虚拟机磁盘**：Parallels、VMware、Docker 等虚拟机与容器磁盘按文件格式识别，只列出不删除，并写明该在哪个软件里删除；创建它的软件已不在本机时如实说明。
- **虚拟机镜像**：按文件结构识别应用自带的 Linux 虚拟机（如 Claude 桌面端 Cowork 的约 10GB 镜像），默认不勾选；虚拟机正在运行时不可勾选。删除后应用下次使用相关功能时会重新下载。
- **开发者缓存**：包括 Homebrew 中已被新版本取代、未被链接的旧版本（`brew cleanup` 在上游有更新时不会自动清理它们）。工程构建产物中若混有发布安装包（.dmg / .pkg 等）或源码文件，只删除可重新编译生成的部分，并在说明中写明保留了什么。
- **大文件与久未使用的文件**：按大小和最近使用时间整理，方便您发现占用空间较多的文件。这类文件默认不勾选，由您决定是否清理。
- **安全边界**：系统关键目录、密钥与凭据等重要位置不在清理范围内；个人文件只会出现在「大文件与久未使用的文件」中，且默认不勾选；正在运行的应用的数据会被标出，默认不勾选。

### 📦 软件卸载
- **连同数据一起卸载**：除了应用本体，还会找出它的偏好设置、支持文件、缓存和容器数据，一并列出供您确认。
- **谨慎判断归属**：依据 Bundle ID、代码签名、共享组声明等证据判断文件归属，证据充分的才默认勾选；把握不大、或可能被其他应用共用的项目默认不勾选，是否删除由您决定。归属判断基于规则推断，无法保证在所有应用上都完全准确，删除前请留意列表内容。
- **后台项清理**：同时找出随软件安装的后台服务与开机自启动项。
- **卸载更稳**：同一应用装了多份时，只删选中的那一份；共享的设置与数据照常列出但默认不勾选，并注明另一份装在哪里（废纸篓里、安装镜像里的旧副本不算）。装在别的应用数据目录里的内置组件，不会连带删掉宿主应用的数据；与本工具共用的数据也会自动保护。
- **同厂应用分开处理**：同一开发者的多款应用尽量各自只带走自己的数据；一个文件同时像是几个应用的，归给标识最具体、且仍安装着的那一个。
- **交叉核对**：每个待删项都会与本机其它仍安装应用的归属判断比对，若另一个应用也可能用到它，就默认不勾选并注明是哪个应用。首次打开软件卸载页时需要在后台准备（耗时随已安装应用数量而定，通常十几秒），完成前分析会稍慢。
- **卸载命令行工具**：在卸载页切换到「命令行工具」，列出 Homebrew（含只提供命令的 Cask，如 Claude Code）、npm / bun 全局包、Cargo、uv tool、pipx 安装的工具，以及 `~/.local/bin` 里的独立程序（同一安装脚本一起放下的命令，如 `uv` 与 `uvx`，合并为一项）。程序本体交给对应的包管理器卸载（如 `brew uninstall --cask claude-code`），卸载命令失败时不会删除任何数据；再按需删除它在 `~/.<名字>`、`~/.config`、`~/.local/share`、`~/.cache` 等处的数据，以及指向它的别名链接。同名桌面应用也在使用的数据（如 Claude 桌面端与 `~/.claude`）默认不勾选。卸载 Homebrew formula 时 Homebrew 会一并移除不再被依赖的库，完成页会列出这些依赖。
- **影片与文稿中的数据**：应用写在「影片 / 音乐 / 图片 / 文稿」文件夹里的数据单独分组列出，默认不勾选。
- **应用内保存的文件**：沙盒应用存在自己容器里的视频、图片、音频、文档单独列出，取消勾选即可在卸载前移到「影片 / 图片 / 音乐 / 文稿」里保留。按下载目录合并成组；应用自带的资源图、缩略图与视频封面、加密存放打不开的图片不算在内。
- **别的软件生成的启动器**：Parallels 为虚拟机里的 Windows 程序生成的 .app、浏览器为网页应用生成的 .app 不会出现在卸载列表里；卸载生成它们的软件时一并列出。装在虚拟机包里的程序同样不单独列出。
- **列表更干净**：应用内置的组件、命令行工具附带的后台链接入口（如 Claude Code URL Handler）不再单独列出；入口指向的程序已被删除时才列出，方便清掉。

### 🤖 AI 数据
- **识别各类 AI 工具**：按目录结构和记录内容识别本机 AI 编程助手与桌面端的数据（如 Claude、Codex、Gemini / Antigravity、Qwen 等），不依赖固定的工具名单，存储方式常见的新工具通常也能识别；识别不到的不会出现在列表中，也不会被删除。
- **支持的存储方式**：一个会话一个文件，或一个会话一个文件夹；会话存在单个数据库里的工具（如 OpenCode）只读展示，请在该工具内删除；键值存储（Cursor）与加密存档（Windsurf、ChatGPT 桌面端）暂不支持。
- **会话记录**：按助手 → 项目列出历史会话，显示标题（取第一条真正的提问，跳过工具拼接的附件说明与粘贴的文件路径）、最后活动时间与占用；可按时间筛选（如 30 天前）后批量选择。会话连同它的快照、产物等关联数据一起移入废纸篓，清空前可放回原处（放回后是否重新出现在工具的会话列表中，取决于该工具自身）。判断为正在进行的会话不可勾选。
- **缓存与旧版本**：助手数据目录里的缓存、日志、临时区，以及被新版本取代、且没有任何配置引用的旧版本（如旧的插件版本）。
- **本地模型**：按文件结构识别模型权重（GGUF / safetensors / ONNX / Core ML、HuggingFace 与 Ollama 分层存储等），以单个模型为单位列出，默认不勾选。
- **不列入清理的内容**：登录凭据、配置、记忆、技能、指令文件，以及仍被配置引用的版本不会被列出；删除前每个路径都会再做一次结构复核，不通过的跳过。

### 🎨 使用体验
- **液态玻璃界面**：遵循 macOS 26 液态玻璃设计，整窗通透磨砂，按钮与搜索框为玻璃质感（macOS 14 / 15 上显示为系统磨砂材质），清理与卸载时以简洁的进度环呈现，没有广告。
- **不常驻后台**：打开即用，关闭窗口后自动退出，不占用后台资源。
- **可见可控**：每一项都显示路径与大小，删不删由您决定。
- **在线更新**：在「关于」页可检查更新，一键升级到新版本。
- **需要管理员权限的项目**：卸载时 `/Library` 等系统目录里的残留，以及废纸篓里其他软件以管理员身份放入的文件，删除时会弹出 macOS 管理员密码框由您确认。本应用不安装常驻后台助手，密码输入一次，在本次运行内有效；可在偏好设置「允许清理需要管理员权限的项目」中关闭，关闭后这类项目只列出、不删除。
- **受保护目录白名单**：偏好设置 → 受保护目录白名单，加入的文件夹（如整个「下载」）及其中所有内容不会出现在任何扫描结果里——系统清理、大文件与重复文件、孤立残留、AI 数据（会话、缓存、模型、工作树）、软件与命令行工具卸载的残留，删除前也会再核对一次，需要管理员权限的项目同样不会被删除。要卸载的应用本体不受白名单限制。添加或移除后重新扫描即生效；系统目录、钥匙串与登录凭据等由内置规则保护，无需添加。
- **诊断日志**：偏好设置 → 诊断日志，开启后记录每次扫描、卸载、清理找到了什么、用了多久、哪里出错，方便反馈问题；点「导出诊断包…」生成 zip 后由您自己发送。默认关闭，只存在本机、最多保留 14 天，不会自动上传。家目录写成 `~`，电脑名、账号类标识、桌面 / 文稿 / 下载 / 废纸篓里的文件名、AI 会话标题都会隐去。

## 📥 下载与安装

前往 **[Releases 发布页面](https://github.com/8wcznkmy6b-del/AuraCleaner/releases)** 下载最新版 DMG 安装包（`AuraCleaner-<版本号>.dmg`）。

双击打开 DMG，把 `AuraCleaner.app` 拖入「应用程序」文件夹即可完成安装。

> 首次打开时如果 macOS 提示无法验证开发者，请前往「系统设置 → 隐私与安全性」，在页面下方点击「仍要打开」。

### 使用前提
- 需要在同一台 Mac 的「应用程序」文件夹中安装 **AuraSnap**，并已激活 **Pro**。


### 系统要求
- macOS 14.0 (Sonoma) 或更高版本
- 搭载 Apple 芯片（M 系列）的 Mac
- 建议授予「完全磁盘访问权限」，以便扫描应用容器等受保护位置；未授权时部分项目无法扫描，软件卸载前也会提示授权
