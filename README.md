# AuraCleaner

> **简洁、安心的 macOS 垃圾清理与软件卸载工具**

---

## 📖 产品简介

`AuraCleaner` 是 AuraSnap 的配套应用，帮您清理 Mac 上不再需要的缓存、日志和残留文件，也能把软件连同它的相关数据一起卸载干净，腾出磁盘空间。

所有扫描结果都会先列出来给您确认，删除的内容默认移入废纸篓，误删也能找回。

---

## 🌟 核心功能

### 🧹 系统清理
- **缓存与日志**：找出系统和应用运行中产生的缓存、日志与临时文件，这类文件删除后会按需自动重新生成。
- **孤立残留**：找出已删除的应用遗留下来的配置与数据文件。
- **大文件与久未使用的文件**：按大小和最近使用时间整理，方便您发现占用空间较多的文件。这类文件默认不勾选，由您决定是否清理。
- **安全边界**：系统关键目录、个人文档、密钥与凭据等重要位置不在清理范围内；正在运行的应用的数据会被标出，默认不勾选。

### 📦 软件卸载
- **连同数据一起卸载**：除了应用本体，还会找出它的偏好设置、支持文件、缓存和容器数据，一并列出供您确认。
- **谨慎判断归属**：只有明确属于该应用的文件才会默认勾选；不确定是否属于它、或可能被其他应用共用的项目只做展示，不会自动删除。
- **后台项清理**：同时找出随软件安装的后台服务与开机自启动项。

### 🎨 使用体验
- **液态玻璃界面**：遵循 macOS 26 液态玻璃设计，整窗通透磨砂，按钮与搜索框为玻璃质感，清理与卸载时以简洁的进度环呈现，没有广告。
- **不常驻后台**：打开即用，关闭窗口后自动退出，不占用后台资源。
- **一切可见可控**：每一项都显示路径与大小，删不删由您决定。
- **自动更新**：在「关于」页可检查更新，一键升级到新版本。

## 📥 下载与安装

前往 **[Releases 发布页面](https://github.com/8wcznkmy6b-del/AuraCleaner/releases)** 下载最新版 DMG 安装包（如 `AuraCleaner-1.0.3.dmg`）。

双击打开 DMG，把 `AuraCleaner.app` 拖入「应用程序」文件夹即可完成安装。

> 首次打开时如果 macOS 提示无法验证开发者，请前往「系统设置 → 隐私与安全性」，在页面下方点击「仍要打开」。

### 使用前提
- 需要在同一台 Mac 的「应用程序」文件夹中安装 **AuraSnap**，并已激活 **Pro**。


### 系统要求
- macOS 14.0 (Sonoma) 或更高版本
- 搭载 Apple 芯片（M 系列）的 Mac
- 建议授予「完全磁盘访问权限」，以便扫描应用容器等受保护位置；未授权时部分项目无法扫描
